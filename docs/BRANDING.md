# Logo credits

The ytm-rsk logo combines the smiling face from [ytm-rs](https://github.com/grapedjuice/ytm-rs) by grapedjuice and contributors with a modified Android robot silhouette. The robot is red instead of green, and the original face is replaced with the ytm-rs smile. The combined artwork was created with image-generation assistance.

- Original ytm-rs icon: [assets/icon/icon.png](https://github.com/grapedjuice/ytm-rs/blob/main/assets/icon/icon.png). The upstream repository is distributed under GPL-3.0; no separate permission or endorsement for its branding is claimed.
- Android reference supplied for this adaptation: [android.svg](https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/android.svg), distributed by homarr-labs/dashboard-icons.
- Android robot: created and shared by Google; modified under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/). See Google's [Android brand guidelines](https://developer.android.com/distribute/marketing-tools/brand-guidelines).

The same red artwork appears in the Android launcher, the app header, and the repository README.
